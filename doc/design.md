# 澄序设计规范

澄序的日常界面采用浅暖灰画布、近黑正文和细边界。蓝色用于主行动、当前导航、焦点和关键数据。状态色和文字配合表达完成、警告或错误。深色使用独立的背景、表面和前景角色，保留相同的层级。

## 视觉层级

- 正文和控件用 Inter，并回退到系统中文字体。大标题使用 Geist 和系统中文字体。正文与标签通常使用常规字重，标题与关键操作使用中等字重。
- 间距沿用项目的 4px 网格。用留白建立分组，只有需要明确区分的内容才使用边框。大表面、内层面板和控件使用各自的圆角，浮层用阴影体现深度。
- 每个页面有一个明确的首要任务。短文案直接说明用途。图标与文字配合，筛选、选择和确认有可见的状态反馈。
- 动效用于说明展开、位置变化或提交结果。沿用 Arc 的动效 token 和减少动态效果偏好。

## 主题与组件

主题数值维护在 [tokens.json](../packages/design-tokens/tokens.json)，功能角色和派生色定义在 [themes.ts](../packages/design-tokens/src/themes.ts)。Web 默认使用 `themes.studio` 的浅暖灰和蓝色，通过 `themeStyle()` 映射到 `--background`、`--surface`、`--accent` 等 Arc 角色。颜色工作台可切换预设、编辑角色、保存到本地和导出。

Web 根布局加载 Arc Foundation，交互优先从本地 Arc 组件组装。组件目录、页面模式、风格和动效可在 `/showcase`、`/patterns`、`/styles`、`/motion` 中预览。业务页面检查键盘焦点、触控范围、长文本和明暗主题，按任务提供加载、空结果、失败与成功状态。

移动端共享设计语义，现有原生实现和主题配置沿用当前版本。后续迁移按平台的触控、手势、安全区和系统辅助功能设计。见 [移动端设计原则](../apps/mobile/README.md#arc-设计原则)。
